# Data provenance and license scope

This repository redistributes a small excerpt of the HoloAssist dataset, recording `R0027-12-GoPro`, plus reformatted measurement tables and visualization videos. The original data is from the HoloAssist research team and is not claimed as new data collected by this repository's uploader.

The original source is https://holoassist.github.io/. The HoloAssist release specifies **CDLA-Permissive-2.0**. The complete license text is included in `LICENSE-DATA.txt`, from the official Community Data License Agreements release:

https://raw.githubusercontent.com/Community-Data-License-Agreements/Releases/main/CDLA-Permissive-2.0.txt

`LICENSE-DATA.txt` accompanies the shared dataset excerpt, exported measurements and redistributed video content. This package does not replace the data license with MIT. A separate software license for the processing scripts has not been selected by the repository owner. Third-party Python packages retain their own licenses and are installed separately through requirements.txt.

Please cite the original HoloAssist paper using `CITATION.bib`. The PSI joint/matrix specification and PyHoloAssist camera-transform implementation are referenced as technical sources in the documentation.

The sample is supplied with documented tracking anomalies. Numerical export and checksum checks do not certify that every sensor pose is physically accurate.
